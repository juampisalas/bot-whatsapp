# Agent instructions

## Language

**All source code must be in English.** This is mandatory for this repository and for every project going forward.

Includes:

- File, folder, type, function, method, variable, parameter, and constant names
- Log messages, error messages, and user-facing strings emitted by code
- Comments and JSDoc inside `src/` and `tests/`

Does **not** require translating:

- Specs, plans, and design docs under `docs/`
- Commit messages (prefer English for new commits; existing history stays)
- Skills or third-party content that already lives outside this project's code

When touching Spanish identifiers left from earlier work, rename them to English in the same change. Do not introduce new Spanish identifiers.
